Nesse codigo, o usuário começa um cadastro de academia, com suas informações pessoais: nome/ idade/ peso/ altura/ genero/
quantidade de refeições/ objetivo final/
o código vai gerar o gasto Kcal/basal TMB, alem do consumo diário esperado de carboidratos, proteinas, gorduras e fibras dentro
da dieta escolhida somada ao objetivo selecionado, uma ficha de treino de iniciação com validade de um semestre vai ser gerada
para seguir, com os aparelhos a seres feitos nos respectivos dias na academia.
